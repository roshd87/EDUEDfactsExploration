# edu_ext_edfacts

EDFacts file output over `edu_wh` marts. Phase 2 of `../EDFactsOutputPlan.md`: spec seeds plus
the count and file macros, proven on FS052 against a fixture population.

- `seeds/edfacts_*.csv` are generated by `python3 tasks/build_edfacts_seeds.py --year 2026-27`
  from `tasks/reports/<year>/federal-table-cells.csv`. Do not hand-edit them. The builder's `SPECS`
  allowlist grows one wave at a time.
- `edfacts_counts(pop, fs, org_level, unit_key, exclude_values)` runs one `GROUP BY` per category
  set, labels each row with its set and Total Indicator, unions the sets, and zero-fills
  permitted values (except `MISSING` and `exclude_values`) for every organization in `pop`.
- `edfacts_file(counts, fs, org_level)` returns `(line_no, record)`: a header at line 0, then the
  fixed-width records, left-justified and space-padded (as Generate does). Set the vars
  `edfacts_state_code`, `edfacts_state_abbr` and `edfacts_submission_id`.
- Tests: `edfacts_conforms` (codes and lengths), `edfacts_sets_sum_to_total`, `edfacts_record_lengths`.

Call the macros namespaced, as `edu_ext_edfacts.edfacts_counts(...)`.

```sh
python3 -m venv ~/.venvs/edfacts-dbt && ~/.venvs/edfacts-dbt/bin/pip install dbt-core==1.9.4 dbt-duckdb==1.9.3
cd edu_ext_edfacts/integration_tests && ~/.venvs/edfacts-dbt/bin/dbt deps --profiles-dir . && ~/.venvs/edfacts-dbt/bin/dbt build --profiles-dir .
```
