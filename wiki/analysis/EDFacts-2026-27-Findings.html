EDFacts SY 2026-27 Findings

What the SY 2026-27 file specifications contain, what changed from SY 2025-26, and which fields are shared across files. Written for the dbt package that will generate EDFacts files from Ed-Fi and EDU/Stadium data.

Sources: 94 DOCX specifications and 43 companion documents fetched from ed.gov on 2026-10-07; full Pandoc extraction of both years; a five-batch field review validated against every layout table. File references are at the end.

2. What changed from SY 2025-26

Three sources agree: the document-history table in each DOCX, a normalized cell-by-cell diff of both years' extractions, and the catalog itself. 83 of 94 documents record editorial edits only. Eleven record a substantive change.

No Data Record Definition or Header Record Definition changed beyond punctuation in any of the 94 files. Layout seeds can be built from either year's extraction.

The broadest change is in vocabulary. The specs now cite EDPass metadata collections FS5002 to FS5029 fifty-seven times, against nine residual "survey" mentions. The state policy answers that Generate kept as toggle questions (count dates, age bands, assessment types offered) are themselves EDFacts files in this cycle.

Content is reusable; position is not. 67 of the 88 shared fields agree on definition, permitted values and length, but only 37 keep a fixed start position. A shared seed can define each field's name, length, type and value set once. Each file's layout seed must supply its own start positions and its own header filler length.

The fixed skeleton

The header record has the same structure in all 94 files: File Type 1/50, Total Records 51/10, File Name 61/25, File Identifier 86/32, Reporting Period 118/9, then Filler from 127 and CRLF. Only the record length varies (270 to 880 bytes). The data record opens with a prefix that is fixed in 73 of 96 data layouts:

Family-wide fields

  • Student counts, assessment and EL: Economically Disadvantaged Status (16 specs), Homeless Enrolled Status (11), Migratory Status (10), Major Racial and Ethnic Groups (9), Foster Care Status (8).
  • Assessment and EL: English Learner Status (Both) (9), Military Connected Student Status (6), Proficiency Status (6), Assessment Administered (ELP) (4), Grade Level (4).
  • IDEA Part B and C: Disability Category (IDEA) (7), Infants and Toddlers Count (4), Lead Agency Number (9).
  • Accountability FS199–FS205: State Defined Status Indicator (5), Major Racial and Ethnic Groups (Accountability) (4).

All family-wide fields have identical permitted values across their specs. Collection-specific fields come in mirrored pairs: Part B and Part C dispute resolution (FS227/FS906, FS228/FS907, FS229/FS908), the N or D pairs, and the FS029/FS190/FS196 address blocks.

4. Looks shared but differs

These are the fields that would break a single shared definition. Each needs a per-spec value in the seeds.

  1. Total Indicator has three value sets. N;Y in 52 specs, N only in 20, Y only in FS193, FS205, FS222 and FS226. Seventeen specs (directory, status and roster files) have none. The accepted-values test is per spec.
  2. Header length is not data length. They differ in 57 of 94 spec versions, so header Filler is a per-spec seed value, not data_length − 127.
  3. State Agency Number and Lead Agency Number share slot 13/2 (both DG570). The value is 01 in SEA files and 02 in the LA Directory (FS029 v23.1) and FS901–FS908. FS906–FS908 still define it as "state agencies".
  4. FS908 prints two definitions swapped relative to FS229 (Due Process Complaint Result and Resolution Meeting Outcome). Codes and positions agree; treat the codes as authoritative.
  5. Same name, different length. Military Connected Student Status is 125 in FS175/178/179 and 15 in FS185/188/189. Student Count is 8 in FS151 and 10 everywhere else. Data Filler runs 7 to 125.
  6. Same identifier, shifted start. School Identifier (State) starts at 36 where an NCES LEA id occupies 29–35 (FS029 School, FS039, FS197). Table Name starts at 44 in FS099 and 29 in FS193. Staff FTE starts at 330, 345 or 145 depending on the file.
  7. Delinquent Programs: FS119 permits MISSING; FS127 does not.
  8. Disability Category (IDEA): FS006 and FS089 add IFSP to the definition; values are identical.

5. What this means for the plan

  • Seed shape. One edfacts_fields seed defines the 67 content-identical shared fields (name, length, type, permitted values) once; each FS### layout seed carries start positions, header filler length, Total Indicator value set and any per-file length override.
  • Config shape. Shape edfacts_config to the FS5002–FS5029 metadata collections, so the same seed emits the metadata files and drives the data files.
  • Scope. Drop FS112 from every rollout list.
  • Rules changed by the new guidance. FS118 cumulative unduplicated count, FS195 once-per-shared-time-school, FS113/FS125 program-type zero exceptions, FS127 count type, assessment "all applicable combinations". Apply each when building that file.
  • Re-check when files go Active. The SY 2026-27 BRSI and any post-unlock spec revisions; refresh with the Chrome fetch and freeze scripts.
