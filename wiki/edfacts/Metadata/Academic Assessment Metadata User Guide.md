## 5.0 Guidance

This section contains questions and answers about the metadata submitted.

### What changes to assessments are reported in FS5006, FS5007, and FS5008?

FS5006, FS5007, and FS5008 have had the following question added:

- **_NEW!_** Did the state make changes to the mathematics assessments in the current school year?

`o` What type of changes were made?

FS5006, FS5007, and FS5008 also have the following questions included:

- Is the SEA planning to make adjustments or significant changes for assessments to be administered in any of the three years following this reporting year?

If the answer is **_Yes_** to the questions above, you will answer the following question: _Which school year is planned for this change?_ And choose one of the following responses:

- _SY after current SY_

- _Second SY after current SY_

- _Third SY after current SY_

### In the change questions, what school year is the “current SY”?

The current SY is the reporting year of data.

### How are changes that occurred to assessments in the current school year (that is, the SY of the data being submitted) reported?

Changes to content, achievement standards and the assessments that took place in SY 2024-25 are reported in the State Submission Plan. The changes should be reported in the SSP of the FS for academic achievement: for mathematics under FS185, for reading/language arts under FS188, and for science under FS189.

When reporting changes for the current year, begin the data note with “Change in Current SY.” The data note should include the type of change (content, achievement standards, and assessments) and which grade levels are impacted by the change. The data note should specifically indicate whether the change impacted the regular/general assessment and/or the alternate assessment.

Below are examples of data notes.

|**Type of Change **|**Example of a data note in the SSP**|
|---|---|
|Content Change|The academic content standards of the assessments for<br>mathematics in grades 3 and 4 were changed in SY 2024-<br>25. This change impacted both the regular/general and<br>alternate assessments for those grades.|
|Achievement Standards|The achievement standards for the alternate assessments<br>for mathematics in grades 3 and 4 was changed in SY<br>2024-25. The achievement standards for the other<br>assessment types did not change.|
|Assessment|The regular assessment for mathematics in grades 3 and<br>4 was changed in SY 2024-25. The alternate assessment<br>for these grades was not changed.|

**When the change question, “Is the SEA planning to make adjustments or significant changes for assessments to be administered in any of the three years following the reporting year?” is responded to with “Yes,” is an explanation of future planned changes to assessments required?**

No. ED is only requesting information about the type of change (content, achievement standards, and assessments) and when those changes are planned. If the SEA has additional information about future planned changes that it wants to provide, that information should be provided under the FS for participation: for mathematics under FS175, for reading/language arts under FS178, and for science under FS179. When providing additional information, please begin the note with “Future changes.”

### How should the grade levels reported in this metadata collection align with data reported in the file specifications?

A state should report the same grade levels in the metadata collection that are reported in the data files. For example, if a state indicates in the metadata that their regular assessments will be using the ‘HS’ permitted value, the state must also report the ‘HS’ permitted value for that assessment type in the data file. If the responses in the metadata collection do not align with the data reported in the data files, DQ errors will be triggered, and the data will not be able to be submitted in EDPass until the errors are resolved by updating the metadata or data files.

### How are these metadata used in business rules?

There are data quality business rules in EDPass that compare the metadata responses to the data uploaded via data files. All business rules can be found in the Business Rules Single Inventory (BRSI) available on the EDFacts Initiative site. The types of business rules that compare assessment metadata to the assessment file data are:

- **_Data Error_** - To resolve the error, the metadata and/or data files must be updated to align.

   - **Permitted values comparison** – compares that the high school permitted values used are either individual grade values (09, 10, etc.) or HS and that they align in the metadata responses and data file for Math and RLA.

- **_Rule Failure_** – Review the uploaded data and if data are accurately reported, add a data note for the file specification by accessing the Data Quality Results page from the Data Submission List for the associated file specification.

   - **Expected:** All permitted value combinations used by the SEA where zero reporting is required are expected to be reported.

   - **Unexpected:** Permitted value combinations not used by the SEA are not expected to be reported in the Grades 3-8 data group for the Academic Achievement in Mathematics file.

   - **Missing Permitted Values (PVs)** - The sum of the Grades 3-8 data group or HS data group in the Assessment Participation in Mathematics file (FS185) is expected to be greater than zero for students with disabilities for all participation statuses used by the SEA.

      - This edit uses the responses to FS5005 (general med exempt question) and FS5006 (assessment types)

To enter information and submit a metadata collection, access a collection data entry page from the Metadata Submission List, enter information, and submit the metadata along with the associated FS listed in Section 4.0.

**_Note!_** The **SAVE** button will not be enabled if responses are missing in any of the cells. ## 7.0 Submitting the Metadata Collection

The assessment metadata must be submitted with the entire data package of assessment data. This means that all required data files and metadata for that package must be in a status of _Ready to Submit_ , to submit all the data in EDPass.

The data packages are:

- Mathematics – Includes FS175, FS185 and Mathematics Assessment Metadata collection

- Reading/Language Arts – Includes FS178, FS188 and Reading/Language Arts Metadata collection

- Science _–_ Includes FS179, FS189 and Science Assessment metadata collection

**_Note!_** The General Assessment Metadata collection can be submitted on its own.

Once the metadata and all related file specifications in the data package reflect _Ready to Submit_ status _,_ select **Submit** from either the Metadata Submission List kebab menu or one of the related files in the data package kebab menu on the Data Submission List. The _Submit Data_ pop-up will appear (see fig. 7.1).

Figure 7.1: Submit Data Confirmation pop-up

Select **Submit** to submit the metadata.

**_IMPORTANT!_** Upon submitting the metadata collection, the status of the data may reflect _Data Submission in Progress_ . The processing time of data files can take between 45 to 60 minutes. Shortening the processing time of data will continue to be a priority.

Once data successfully processes, _Submitted_ will display (see fig. 7.2).

Figure 7.2: Status of Submitted reflected upon successful submission

If updates to data need to be made after a due date has passed, please contact PSC.
