## 1.0 Purpose

This document contains instructions for submitting the Determination Data Year Metadata, which has been assigned FS5029 (DG2093).

This metadata collection is part of the MOE/CEIS/CCEIS data collection, which includes the following files:

- FS231 (DG898, DG899, DG900) – IDEA Part B Allocations

- FS232 (DG901, DG902, DG903, DG904) – MOE Status

- FS233 (DG905, DG906) – MOE Funds

- FS234 (DG907, DG908) – CEIS and CCEIS Provisions

- FS235 (DG909) – Significant Disproportionality Reason

- FS236 (DG910, DG911) – CEIS and CCEIS Reservations

- FS237 (DG912, DG913) – Children Receiving CEIS

- FS238 (DG914) – Children Receiving CCEIS

The ED data stewarding office is OSEP.

## 5.0 Completing the Metadata Collection

To enter information and submit a metadata collection, access the collection data entry page from the Metadata Submission List, enter information, and submit the metadata along with the associated FS listed in section 1.0.  Updates can be made up to the due date.  The metadata responses can be downloaded at any time.

From the EDPass Landing Page, select **Submission List** from the top menu bar (see fig. 5.1).

The default view on this page is the _Data Submission List._ Select **Metadata Submission List** to access the list of metadata collections.

To return to the Data Submission List at any time, select the **Data Submission List** tab (see fig. 5.1).

Figure 5.1 – Submission List with Data Submission List and Metadata Submission List tabs

### 5.1 Accessing the Metadata Collection

To access the metadata collection, select _Edit/Enter Metadata_ from the kebob menu next to FS5029 **Determination Data Year Metadata** on the Metadata Submission List page (see fig 5.2).

### 5.2 Responding to the Metadata Collection

#### MOE/CEIS/CCEIS

Respond to the question, **_What year's data were used to make LEA/ESA determinations in the state?_** by clicking **EDIT** and then selecting the applicable school year from the drop-down menu (see fig. 5.3). The following years are available in the drop-down menu:

- SY 2024-25

- SY 2023-24

- SY 2022-23

- SY 2021-22

- SY 2020-21

Figure 5.3 – The edit button- and drop-down menu on the metadata entry page

**_NOTE!_** If the user selects SY 2020-21 or SY 2021-22 the system will display a message that says, “The Year used to make the LEA/ESA determinations is not the current or two prior years (SY 2024-25, 2023-24, 2022-23, for SY 2024-25 cycle). Please resubmit the data and/or provide a data note with an explanation.” The Comment field (4,000character limit) will be required if SY 2020-21 or SY 2021-22 is selected.

After selecting the applicable answer and entering a comment, if necessary, click **SAVE** (see fig. 5.4).

Figure 5.4 – Drop-down menu, save button and optional comment box

### 5.3 Submitting the Metadata Collection

Once the metadata and all related file specifications listed in section 1.0 reflect a status of _Ready to Submit,_ select **Submit** from the kebab menu for either one of the file specifications from the Data Submission List or the metadata collection from the Metadata Submission List.

The _Submit Data_ pop-up will appear.

Upon selecting **Submit,** a _Confirm Submission_ pop-up will appear.

Select **Submit** to submit the metadata.

**_IMPORTANT!_** Upon submitting the data package, the status of the data files and metadata may reflect _Data Submission in Progress_ on the Submission Lists. The processing time of data can take between 45 to 60 minutes. Shortening the processing time of data will continue to be a priority.

Once data are successfully processed, the status of _Submitted_ will display on both the Data Submission List (data files) and Metadata Submission List.

After a due date, all data and metadata (as applicable) are delivered to ED.

### 5.4 Making Updates to Submitted Metadata

Updates can be made to the metadata collection after it has been submitted up until the due date.

Making updates will change the status on the Metadata Submission List. Follow the process of submitting the metadata and data again to complete the submission process.

If updates to the metadata and/or data need to be made after a due date has passed, please contact PSC for guidance.

### 5.5 Downloading the Responses to the Metadata Collection

To download a copy of the saved or submitted responses to the metadata form, select **Download Metadata** from the kebab menu on the Metadata Submission List (see fig. 5.5).

Prior year submissions can be downloaded on the Metadata Submission List by locating the FFY 2023/SY 2023-24 FS5029 **Determination Data Year Metadata** and selecting **Download Metadata** from the kebab menu on the Metadata Submission List (see fig. 5.5).
