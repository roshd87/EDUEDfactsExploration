## 5.0 Guidance

This section contains questions and answers about the metadata submitted.

### Where are the indicator measures and state-defined subgroups a state uses for ESEA Title I accountability defined?

A state defines the indicator measures it uses for each of five types of indicators and any state-defined subgroups it also uses for ESEA Title I accountability in its approved ESEA consolidated state plan.

A state may request to amend its ESEA consolidated state plan, and such amendments may change the indicator measures the state for ESEA Title I accountability and any state-defined subgroups the state has defined for ESEA Title I accountability. As a result, when reporting data for EDFacts and accountability metadata, a state must report data based on the its approved ESEA consolidated state plan for **the reporting year** (e.g., a state must report data for the 2024-2025 EDFacts collections based on its approved ESEA consolidated state plan used for school year 2024-2025 ESEA Title I accountability.)

If an EDFacts Coordinator has any questions about the indicator measures or any statedefined subgroups used by the state for ESEA Title I accountability, the Coordinator should contact the state’s Title I, Part A Director.

### How are accountability metadata and data a state reports for indicator files and the Identification School Support and Improvement file related to a state’s approved ESEA consolidated state plan for the reporting year?

As part of ESEA Title I accountability as described in the state’s approved ESEA consolidated state plan for the reporting year, a state annually determines school and subgroup performance on the indicator measures the state uses for ESEA Title I accountability and identifies schools for support and improvement based on school or subgroup performance.

A state reports school and subgroup performance on the indicator measures to EDFacts for FS199, FS200, FS201, FS202 and FS205. For schools identified for support and improvement based on subgroup performance, a state reports the reasons to EDFacts for FS212. When a state has defined one or more state-defined subgroups, it reports for subgroups for which there are permitted values and any state-defined subgroup(s).

A state reports metadata to identify and describe the indicator measures and statedefined subgroups it reports to EDFacts .

The accountability metadata should match the EDFacts data (indicator data and data for FS212) a state reports and both should be consistent with the state’s approved ESEA consolidated state plan for the reporting year.

### How should the indicator measures reported in these metadata collections align with data reported in the file specifications?

A state should report the same indicator measures in the metadata collections that are reported in the data files.

December 2025 3

For example, if a state indicates in the metadata that its Academic Achievement indicator measures are AAM01 and AAM02 permitted values, the state must also report the same permitted values for the indicator type in the FS200 data file. If the indicator measures in the metadata collections do not align with data reported with the same permitted values in the data files, DQ errors will be triggered, and the data will not be able to be submitted in EDPass until the errors are resolved by updating the metadata or data files.

Similarly, for each academic indicator measure, a state should report state-defined statuses in the FS200 data file consistent with the measures reported in the metadata collection (e.g., numbers on the scale reported for an Interval Data – Index; the performance levels using the reported labels).

### How does a state report the state name for an indicator measure for the Accountability Metadata Collection?

A state should report a state name for each indicator measure that parallels the name for the indicator defined in the state’s approved ESEA consolidated state plan for the reporting year. In addition, the state should ensure the name reported for an indicator measure is distinct from the name used for any other indicator measure.

For example, a state may have defined an Academic Achievement indicator measure for academic achievement in mathematics, reported the data file as AAM01, and an Academic Achievement indicator measure for academic achievement in reading/language arts, reported in the data file as AAM02. The state would report metadata with academic achievement in mathematics as the name for AAM01 and academic achievement reading/language arts as the name for AAM02. Providing “academic achievement” as the name for both AAM01 and AAM02 would not be sufficient because the name does not distinguish between the two indicator measures.

### When does a state report “Ordinal – Performance levels” for the type of scale used for an indicator measure?

A state reports “Ordinal – Performance levels” for the type of scale used for an indicator measure when the categories of possible outcomes for school and subgroup are ranked ordered from lower to higher performance but the performance differences between categories may not be uniform or quantifiable (e.g., Red, Orange, Yellow, Green; Below Expectations, Meets Expectations, Exceeds Expectations).

When a state reports “Ordinal – Performance levels” for the type of scale used for an indicator measure, the state also reports the labels for each of the performance levels.

### When does a state report “Nominal – Met/not met” for the type of scale used for an indicator measure?

A state reports “Nominal – Met/not met” for the type of scale used for an indicator measure when there are only two categories of possible outcomes for school and subgroup performance on in indicator measures (e.g., met/not met, pass/did not pass, at or above target/below target).

### When does a state report “Interval – Percentage scale” for the type of scale used for an indicator measure?

A state reports “Interval – Percentage scale” for the type of scale used for an indicator measure when the scale used for possible outcomes for school and subgroup performance is a percentage scale with a range from zero percent to 100 percent.

### When does a state report “Interval – Index” for the type of scale used for an indicator measure?

A state reports “Interval – Index” for the type of scale used for an indicator measure when the scale used for possible outcomes for school and subgroup performance an index that rank orders possible outcomes for school and subgroup are ranked ordered from lower to higher performance and the performance differences between possible outcomes are meaningful and quantifiable (e.g., scale scores for achievement data).

When a state reports “Interval – Index” for the type of scale used for an indicator measure, the state also reports the Lowest Possible Numerical Value and Highest Possible Numerical Value for the index.

### When does a state report “Other” for the type of scale used for an indicator measure?

A state reports “Other” for the type of scale used for an indicator measure when the scale used is not clearly one of the other options (i.e., Nominal Data, Ordinal data - Performance Levels, Interval data - Percentage scale, or Interval data – Index). When a state reports “Other” for the type of scale used for an indicator measure, the state also provides a brief description of the other type of scale.

For example, a state that uses a percentile scale for an indicator measure might provide the following description: Percentile scale, with state-defined statuses on a scale of 0 to 100.

### How does a state report the lowest and highest grades to which an indicator measure applies for the Accountability Metadata Collection?

A state reports the lowest and highest grades to which an indicator measure applies, even if the indicator measure does not apply to some of the grades in between. For example, a state with science assessments in grades 4, 8 and 11 may define an indicator measures for science achievement for its School Quality and Student Success (SQSS) indicator. In this example, the state would report grade 4 as the lowest grade to which the indicator measure applies and grade 11 as the highest grade to which the indicator measure applies, and there may be no data for certain schools with grades in between (e.g., grade 5-6 schools and grade 9-10 schools).

A state that uses a high school end-of-course assessment for an indicator measure reports the lowest and highest grades for which results are included in the indicator measure. For example, a state may administer a high school end-of-course assessment in biology for an indicator measure for high school science achievement for its School Quality and Student Success (SQSS) indicator and typically assess students in grade 10 but also assess students in grades 9, 11, 12. The state would report grade 9 as the lowest grade to which the indicator measure applies and grade 12 as the highest grade to which the indicator measure applies, because student results across these grades are included in the indicator measure.

### For what subgroups does a state provide metadata?

A state is only required to report subgroup metadata if the state has state-defined subgroups for ESEA Title I accountability in the state’s approved ESEA consolidated state plan for the reporting year. The permitted values for these state-defined subgroups are STEDFNDSUBGRP1, STEDFNDSUBGRP2, and STEDFNDSUBGRP3. This does not include the subgroups for which there are permitted values for the specific subgroup (i.e., economically disadvantaged students, students with disabilities, English learners, and the major racial and ethnic groups [e.g., American Indian/Alaska Native/Native American, Asian, Asian/Pacific Islander, Black (not Hispanic) African American, Filipino, Hispanic (not Puerto Rican), Hispanic/Latino, Multicultural/Multiethnic/Multiracial/other, Native Hawaiian/other Pacific Islander/Pacific Islander, Puerto Rican, and White (not Hispanic)/Caucasian]).

If a state has defined one or more state-defined subgroups other than those for which there are permitted values for the specific subgroup, the state reports the state name for each state-defined subgroup for the Accountability Metadata Collection. A state may report up to three state-defined subgroups in the Accountability Metadata Collection.

For example, in lieu of a Native Hawaiian/other Pacific Islander/Pacific Islander subgroup, a state may define a Native Hawaiian subgroup and an Other Pacific Islander subgroup. The state would report these two subgroups separately, as state-defined subgroup 1 and state-defined subgroup 2. A state also may define a subgroup based on student characteristics other than race and ethnicity, such as a lowest-performing

student subgroup or an at-risk students subgroup consisting of economically disadvantaged students, English learners and children with disabilities.

The state-defined subgroup metadata are relevant to the data files a state reports for subgroups for the indicator files (FS199, FS200, FS201, FS202) and the Identification School Support and Improvement data file (FS212).

### How are these metadata used in business rules?

There are data quality business rules in EDPass that compare the metadata responses to the data uploaded via data files. All business rules can be found in the Business Rules Single Inventory (BRSI) available on the EDFacts Initiative site. The types of business rules that compare accountability metadata to the indicator and Identification School Support and Improvement file data are:

- **_Rule Failure_** – Review the uploaded data and, if data are accurately reported, add a data note for the file specification by accessing the Data Quality Results page from the Data Submission List for the associated file specification.

   - **Expected:** Indicator type permitted values and state-defined subgroup permitted values reported in the data files are expected to align with reported metadata.

## 6.0 Completing a Collection

To enter information and submit a metadata collection, access a collection data entry page from the Metadata Submission List, enter information, and submit the metadata along with the associated FS listed in Section 4.0.

Updates can be made up to the due date. The metadata responses can be downloaded at any time.

- **6.1 Accessing the Metadata Submission List**

From the EDPass Landing Page, select **Submission List** at the top menu bar (see fig. 6.1).

The default view on this page is the _Data Submission List._ Select **_Metadata Submission List_** to access the list of metadata collections.

To return to the Data Submission List at any time, select the **Data Submission List** tab (see fig. 6.1).

### 6.2 Navigation on the Metadata Page

To navigate to a metadata collection, from the Metadata Submission List tab, select **Enter/Edit Metadata** from the kebab menu on the right side of the screen (see fig. 6.2).

The navigation buttons on these forms function as follows:

- _Add Subgroup_ or _Measure:_ To add an additional subgroup or measure

- _Remove Subgroup_ or _Measure:_ To remove a subgroup or measure

- _SAVE:_ To save information entered into the form to the database, select **SAVE**

- _BACK:_ Select **BACK** to return to the Metadata Submission List. If data entered are not saved, a pop-up will appear asking whether or not the information should be saved.

Figure 6.2 - Access the data entry page for metadata collections via kebab menu

To begin data entry on a page or make updates to already entered data, select **EDIT** and the data entry cells will appear.

Once all data are entered and data are ready to be saved, select **SAVE** at the bottom of the screen. When the **SAVE** button is clicked, if no error messages are generated, the responses entered will be saved to the database.

**_Note!_** The **SAVE** button will not be enabled if responses are missing in any of the cells. Attempting to navigate away from the metadata form enabled for data entry to another page in EDPass (DSL for example) will trigger the _Unsaved Changes_ error message to appear. Select **Stay** to remain on the page to complete data entry and save the information entered or select **Leave without Saving** to navigate to another section, which will result in lost data.

Closing the EDPass browser window without selecting **SAVE** will result in lost data. Data will be saved only when **SAVE** has been selected. If the screen is in exit data entry mode after **SAVE** is clicked, check the data entry page for missing responses.

### 6.3 Metadata Submission List Status

If all data are not entered and saved, the status on the metadata submission list will reflect _No Data in EDPass_ . Once the form has at least one accountability entry and has been saved, the status on the Metadata Submission List will reflect one of the following statuses:

_Errors:_ a metadata collection that is part of a data package will reflect this status after data entry is complete and saved and the related data file is not uploaded into EDPass

_Ready to Submit_ : a metadata collection that is _not part of a data package_ will reflect this status after data entry is complete and saved, or a metadata collection that is part of a data package will reflect this status after data entry is complete and saved and the related data file is successfully uploaded into EDPass and no DQ errors exist

## 7.0 Submitting the Metadata Collection

Each accountability metadata collection must be submitted as such:

- indicator metadata as part of a data package with the respective data file specification, or

- state-defined subgroup metadata by itself (not part of a data package).

All required data files and metadata for a specific data package must be in a status of _Ready to Submit_ , to submit in EDPass.

Once the metadata and related file specification in the data package (as applicable) reflect _Ready to Submit_ status _,_ select **Submit** from either the Metadata Submission List kebab menu or one of the related files in the data package kebab menu on the Data Submission List.

The _Submit Data_ pop-up will appear..

Upon selecting **Submit,** a _Confirm Submission_ pop-up will appear.

December 2025 18

Select **Submit** to submit the metadata.

**_IMPORTANT!_** Upon submitting the data , the status of the data may reflect _Data Submission in Progress_ on the DSL and MSL. The processing time of data can take between 45 to 60 minutes. Shortening the processing time of data will continue to be a priority.

Once data successfully processes, the _Submitted_ status will display.

After a due date, all data (as applicable) are delivered to ED.

### 7.1 Making updates to Submitted Metadata

Updates can be made to the metadata collection after it has been submitted as long as the due date has not passed.

Making updates will change the status on the Metadata Submission List. Follow the process of submitting the data again to complete the submission process.

If updates to data need to be made after a due date has passed, please contact PSC.

## 9.0 Appendix A

**ACCOUNTABILITY METADATA COLLECTION**

This metadata collection relates to the collection of data on Title I, Part A accountability systems for ESEA, as amended by ESSA as defined in approved ESEA consolidated State plans for the reporting year. This metadata collection relates to the following EDFacts Submission System (ESS) file specifications:

- FS199 Graduation Rate Indicator Status

- FS200 Academic Achievement Indicator Status

- FS201 Other Academic Indicator Status

- FS202 School Quality or Student Success Indicator Status

- FS205 Progress Achieving English Language Proficiency Indicator Status

- State-Defined Subgroups (FS199, FS200, FS201, FS202 and FS212)

For purposes of this metadata collection, a measure is a component part of an indicator. For example, the Academic Achievement indicator could be composed of a measure for mathematics and a measure for reading/language arts. For each measure for an indicator, a State reports school performance using State-defined statuses for the measure. ED proposes collecting this metadata survey manually for at least the first year to allow states more flexibility in responding to this collection.
