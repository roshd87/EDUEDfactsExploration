## 2.0 Completing a Collection

To enter information and submit a metadata collection, access a collection data entry page from the Metadata Submission List, enter information and when the status is _Ready to Submit_ , submit the metadata. Updates can be made up to the due date, and the metadata responses can be downloaded at any time.

### 2.1 Accessing the Metadata Submission List

From the EDPass Landing Page, select **Submission List** at the top menu bar.

The default view of the Submission List page is the _Data Submission List_ tab _._ Select **Metadata Submission List** to access the list of metadata collections.

To return to the Data Submission List at any time, select the **Data Submission List** tab (see fig. 2.1).

### 2.2 Navigation on the Metadata Page

To navigate to a metadata collection data entry page, from the **Metadata Submission List** tab, select **Enter/Edit Metadata** from the kebab menu on the right side of the screen (see fig. 2.2).

Figure 2.2 - Access the data entry page for metadata collections via kebab menu.

To begin data entry on a page or make updates to already entered data, select **EDIT** and the data entry cells will appear.

Once all data are entered and data are ready to be saved, select **SAVE** at the bottom of the screen. When the **SAVE** button is selected, the system will generate any error messages that apply.

**_Note!_** The **SAVE** button will not be enabled if responses are missing in any of the cells. Attempting to navigate away from the metadata form enabled for data entry to another page in EDPass (DSL for example) will trigger the _Unsaved Changes_ error message to appear (see fig. 2.3). Select **Stay** to remain on the page to complete data entry and save the information entered or select **Leave without saving** to navigate to another section, which will result in lost data.

Closing the EDPass browser window without selecting **SAVE** will result in lost data. Data will be saved only when **SAVE** has been selected. If the screen is in exit data entry mode after **SAVE** is clicked, check the data entry page for missing responses.

If a metadata collection does not have responses entered and saved, the status on the metadata submission list will reflect _No Data in EDPass_ . Once all questions have responses and have been saved, the status on the Metadata Submission List will reflect _Ready to Submit_ .

### 2.4 Responding to FS5027 - IDEA Part C Child Count Metadata

The FS5027 — Infants and Toddlers with Disabilities (IDEA Part C) Count Metadata has been developed to collect data authorized under Section 618 of IDEA, Part C of the Individuals with Disabilities Education Act (IDEA). The metadata provides information on the following and is organized to provide the counts for the number of children in the following sections:

- IDEA Part C Child Count Date

- IDEA Part C Cumulative Count Start Date

- IDEA Part C Cumulative Count End Date

- IDEA Part C Cumulative Count Explanation

Metadata will be collected for the 50 states plus the District of Columbia, Puerto Rico, U.S. Virgin Islands, Bureau of Indian Education, and the outlying areas American Samoa, Guam, and Northern Marianas.

#### IDEA Part C Child Count Date

Enter the state’s IDEA child count date using the **Month** and **Date** dropdowns. **_Note!_** Child count date must be between **10/1/2025 and 12/1/2025** (inclusive).

Figure 2.4 – Child Count Date section of the form.

**IDEA Part C 12 Months for the Cumulative Count**

Respond to the question, **_What are the start and end dates for the 12 month period for the cumulative count?_** by entering the _Start_ and _End_ dates of the most recent 12-month period for which the cumulative count of infants and toddlers, ages birth through 2, who received early intervention services are available. For example, if data on the total number of infants and toddlers served during the period from July 1, 2024, through June 30, 2025, are available, report the corresponding dates in this Section.

**_Note!_** A business rule warning will fire for this section if the date of the reference period for the Cumulative Count of Infant and Toddlers, ages birth through 2 who received early intervention services exceeds the first Wednesday of April for the reporting year.

Figure 2.5 – Child Count Date section of the form.

## 3.0 Submitting the Metadata

The metadata must be submitted with the related file specifications. This means that the required data file and metadata for that package must be in a status of _Ready to Submit_ , to submit in EDPass.

The data packages:

- [[FS902 Infants and Toddlers with Disabilities (IDEA Part C) Early Intervention|FS902]] – Infants and Toddlers with Disabilities (IDEA Part C) Early Intervention

- [[FS903 Children with Disabilities (IDEA Part C) Continuing Early Intervention|FS903]] – Children with Disabilities (IDEA Part C) Continuing Early Intervention

- [[FS904 At Risk Infants and Toddlers with Disabilities (IDEA Part C)|FS904]] – At Risk Infants and Toddlers with Disabilities (IDEA Part C)

- [[FS905 Infants and Toddlers with Disabilities (IDEA Part C) Cumulative Count|FS905]] – Infants and Toddlers with Disabilities (IDEA Part C) Early Intervention Services

Once the metadata and the related file specification in the data package reflect _Ready to Submit_ status _,_ select **Submit** from either the Metadata Submission List kebab menu or the related files in the data package kebab menu on the Data Submission List.

The _Submit Data_ pop-up will appear.

Upon selecting **Submit,** a _Confirm Submission_ pop-up will appear.

Select **Submit** to submit the data package.

**_IMPORTANT!_** Upon submitting the metadata collection, the status of the data may reflect _Data Submission in Progress_ . The processing time of data files can take between 45 to 60 minutes. Shortening the processing time of data will continue to be a priority. Once the data is successfully processed, the _Submitted_ status will display.

After a due date, all data (as applicable) is delivered to ED.
